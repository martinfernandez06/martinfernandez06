### Sobre mí

Programo desde 2023. Empecé por el front, con React y JavaScript, armando proyectos como sitios de e-commerce, y para alojarlos trabajé con Firebase. No me considero un experto en Firebase, pero sé usarlo y resolver con él lo que necesito. También manejo Bootstrap y su sistema de SASS para el estilado.

En la universidad terminé de incorporar la parte que me faltaba, la lógica, el back y el diseño de sistemas. Con esa base hoy me desempeño como desarrollador full stack. Trabajo con C# y .NET, estoy sumando ASP.NET para el desarrollo web, y en mis tiempos libres sigo estudiando para profundizar en PostgreSQL.

Estoy próximo a terminar la Tecnicatura Universitaria en Programación en la UTN Facultad Regional General Pacheco. Me considero una persona a la que le gusta resolverle el problema a la gente de principio a fin. Disfruto arrancar desde la estructura y la lógica del sistema en el back, diseñar la base de datos, y recién al final hacer que todo funcione en conjunto. No me gusta encargarme únicamente de un ABM y nada más, ya sea front, back o base de datos, me gusta involucrarme en todo el proceso.

### Cómo trabajo con la IA

Estamos en 2026 y la inteligencia artificial es parte del día a día, pero soy de los que se resisten a que la IA lo haga todo. La uso, sí, sobre todo para organizarme con las tareas y los tiempos, o cuando me encuentro con un problema difícil y quiero saber qué camino es el más conveniente.

Ahora, a la hora de programar, prefiero hacerlo a mano. Cuando quiero aprender un lenguaje, un framework o algo de base de datos, me tomo el tiempo que haga falta para aprenderlo de verdad, leyendo y practicando, a la vieja escuela. Recién cuando ya domino esa herramienta empiezo a apoyarme en la IA. No me parece buena idea usarla con lenguajes que uno no conoce, si la IA se equivoca en algo y yo no tengo el conocimiento para darme cuenta, ese error pasa igual. Por eso primero aprendo, y después sumo la ayuda.

### Proyectos
**Sistema de gestión en C# y .NET · UTN FRGP**
Trabajo práctico de Programación III. Una aplicación de escritorio en C# con Windows Forms, conectada a SQL Server mediante ADO.NET. Está organizada en capas (negocio y datos) y resuelve el circuito completo de altas, bajas y modificaciones, con lectura de datos relacionados entre tablas y validaciones sobre los formularios. El proyecto donde estoy aplicando de lleno la lógica de back y el manejo de base de datos que vengo trabajando en la carrera.
`C#` `.NET` `Windows Forms` `ADO.NET` `SQL Server`
🔗 **[Ver repositorio](https://github.com/AugustoMartinFernandez/tp-winform-equipo-A.git)**

**NeoVape · E-commerce con React y Firebase**
Proyecto final de la Carrera de Desarrollo Web Front-End en Coderhouse. Una tienda online hecha con React y Vite, con el carrito y el checkout resueltos de forma transaccional sobre Firestore para validar el stock en tiempo real y evitar que dos compras se pisen entre sí, además de reglas de seguridad para proteger los datos.
`React` `Vite` `Firebase` `Firestore`
🔗 **[Ver repositorio](https://github.com/AugustoMartinFernandez/Neovape.git)**

**Academia Ninja · Base de datos en SQL Server**
Trabajo Integrador de Base de Datos II. Una base de datos completa modelada sobre el universo de Naruto, normalizada hasta 3FN, con vistas, procedimientos almacenados, triggers y manejo de transacciones. Toda la lógica del negocio resuelta del lado del motor.
`SQL Server` `T-SQL`
🔗 **[Ver repositorio](https://github.com/AugustoMartinFernandez/Academia_Ninja.git)**

**SistemaBarberia · Gestión con C++ y POO**
Sistema de gestión para una barbería desarrollado en C++ aplicando programación orientada a objetos. Modelado de clases, encapsulamiento y la lógica del negocio resuelta desde cero.
